### 🚀 Some things I've built

**🤖 Cable-Driven Robot**  
Designed and programmed a large-scale robotic system controlled by four motors and cables. Worked with inverse kinematics, camera-based tracking, and Kalman filtering to control its movement.

**🌱 Connected Plant Watering System**  
Built an IoT plant monitoring and watering system using an ESP8266, environmental sensors, MQTT, and a Node-RED dashboard. Also experimented with gesture-based interaction.

**📱 Android Applications**  
Developed Android applications in Java, including a personal mood-tracking app and a collaborative event lottery system using Firebase.

**🧩 Sudoku Solver**  
Implemented a constraint-based Sudoku solver in C#, using techniques such as forward checking and the Minimum Remaining Values heuristic.

**🎨 Interactive Experiments**  
Created interactive projects exploring algorithms and visual computing, including Mandelbrot fractals, Langton's Ant, and drawing tools.
